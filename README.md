# Диносчёт

Лёгкая игра для ребёнка, который считает до 10 и учится складывать и вычитать. Игра открывается сразу на первом задании.

## Как играть

1. Посчитать листочки или решить пример по картинке.
2. Выбрать один из четырёх ответов. Листочки можно отмечать касанием, чтобы не пересчитать один предмет дважды.
3. За правильный ответ вылупляется один динозаврик, появляется решение и объяснение.
4. После пяти заданий игра предлагает отдохнуть или начать ещё одну серию.

Неверный ответ сохраняет текущее задание и даёт подсказку. При вычитании убранные листочки перечёркнуты. Случай с нулём объясняется отдельно. Таймера, штрафов и автоматического перехода к следующему примеру нет.

В парке шесть видов динозавров. За каждый ответ коллекция увеличивается на одного малыша, в том числе после открытия всех видов. Коллекция, серия и статистика сохраняются в `localStorage` этого браузера. Они не синхронизируются между устройствами; очистка данных браузера удаляет сохранение. Если хранилище недоступно, игра работает и показывает предупреждение о сохранении.

В настройках для взрослых можно выбрать предел 5 или 10, смешанные задания либо один навык и включить короткий звук награды. Кнопка «Послушать» использует синтез речи устройства при наличии подходящего голоса. Голос не обязателен для игры.

## Устройство приложения

- `docs/` — весь сайт для GitHub Pages: HTML, CSS, ES-модули и SVG.
- `docs/engine.mjs` — генерация задач, проверка ответов, коллекция и сохранения.
- `docs/app.mjs` — интерфейс, касания, диалоги и необязательный звук.
- `docs/art.mjs` — векторные динозаврики и предметы для счёта.
- `tests/` — проверки логики, файлов и поведения в браузерах.
- `scripts/serve.mjs` — локальный сервер для разработки и тестов.

В приложении нет зависимостей времени выполнения, внешних шрифтов, картинок с CDN, аналитики, рекламы, аккаунтов и запросов к серверу за заданиями. Playwright — зависимость только для разработки. После загрузки страницы игру можно продолжать при пропадании сети. Повторный запуск закрытой страницы без интернета не поддерживается.

## Запуск и проверки

Для разработки нужен Node.js 20 или новее. Для игры на опубликованном сайте Node.js не нужен.

```sh
npm ci
npm start
```

Локальный адрес: `http://127.0.0.1:4173/dinosaur-game/`.

Проверки арифметики, сохранений, состава файлов и проектного пути Pages:

```sh
npm test
```

Проверки браузера (в фоновом режиме, без видимого окна):

```sh
npx playwright install chromium webkit
npm run test:browser
```

Для WebKit в PowerShell:

```powershell
$env:BROWSER = 'webkit'
npm run test:browser
Remove-Item Env:BROWSER
```

`BASE_URL` позволяет прогнать тот же набор проверок на опубликованном сайте. Проверки создают изолированный профиль браузера; результаты игры пользователя не затрагиваются. Отчёты пишутся в `test-results/` и не публикуются на сайте.

## Публикация

GitHub Pages должен использовать ветку `main` и папку `/docs`. В `docs/.nojekyll` отключена обработка Jekyll. Все пути ресурсов относительные и работают в `/dinosaur-game/`. Сборка приложения не нужна. После изменения файлов в `docs/` и отправки коммита GitHub Pages обновляет сайт.

Основной пользовательский сценарий — открыть ссылку на смартфоне и сразу играть. Вёрстка адаптирована для небольших экранов, масштабирование страницы разрешено. Сниженное движение (`prefers-reduced-motion`) отключает анимацию появления динозаврика.

Тестирование WebKit на Windows с параметрами iPhone проверяет движок и мобильную вёрстку. Работа на физическом iPhone, качество русского голоса и системные ограничения звука требуют проверки на самом устройстве.
