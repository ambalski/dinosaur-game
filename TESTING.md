# Проверки Диносчёта

Локальные проверки выполнены 16 октября 2026 года.

| Набор | Результат |
| --- | --- |
| Node.js: арифметика, состояние, файлы сайта, HTTP | 14 из 14 |
| Chromium: сценарии браузера | 15 из 15 |
| WebKit 26.5: сценарии браузера | 15 из 15 |

Проверено 20 000 сгенерированных задач: допустимые числа, точное равенство, четыре различных варианта ответа и наличие правильного варианта. В каждой смешанной серии встречаются все три навыка. Проверены ноль, неверный ответ, повторная попытка, двойное нажатие, перезагрузка после награды, завершение серии и изменение настроек.

Браузерные сценарии включают касания, пересчёт предметов, две группы при сложении, перечёркнутые предметы при вычитании, парк, клавиатуру, закрытие диалогов, уменьшение движения, отсутствие внешних запросов и ошибок JavaScript. Проверены ширины 320, 375, 390, 430, 768 и 1280 пикселей, включая задания 5 + 5 и 9 + 1. Проверены заблокированное хранилище, повреждённое сохранение и продолжение загруженной игры без сети.

Тесты используют изолированные профили и фоновый запуск браузеров. Пользовательские вкладки не открываются. Отчёты записываются в `test-results/`.

Границы проверки: тесты WebKit выполняются на Windows с параметрами iPhone, физический iPhone не использовался. Русский системный голос и реальное звучание на телефоне не проверялись. Ручная визуальная проверка не выполнялась. Масштабирование разрешено, но всех сочетаний системного размера текста и настроек доступности тесты не охватывают.

Для проверки публикации: `node scripts/verify-live.mjs`. Команда сравнивает SHA-256 шести файлов приложения с доступными по HTTPS файлами GitHub Pages. Браузерные сценарии можно повторить с `BASE_URL=https://ambalski.github.io/dinosaur-game/`.
